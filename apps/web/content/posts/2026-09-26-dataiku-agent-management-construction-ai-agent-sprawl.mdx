Fewer than one in five companies know every AI agent they're running, so a startup just built software to find them. Construction already has this problem — Procore's own no-code Agent Builder lets any project manager spin up an agent with project access, and nobody at most firms has a list of how many exist.

## What did Dataiku launch?

On September 24, Dataiku launched Agent Management, a standalone product that scans the platforms enterprises already use to build and run AI agents — AWS Bedrock, Databricks Agents, Google Vertex, Microsoft Copilot Studio and Azure Foundry, Salesforce Agentforce, Snowflake Cortex, Dataiku itself, and custom environments through OpenTelemetry — and pulls them into a single inventory. For each agent it finds, the tool maps the models and tools it depends on, tracks how well it's actually performing, and assigns it a risk tier based on how much autonomy it has, how sensitive the data it touches is, and how much business impact a mistake would cause. Agents with access to customer data, production systems, or financial records get flagged as high risk and routed toward mandatory review before they keep running unsupervised.

Dataiku's own numbers explain why it built this now: fewer than one in five organizations maintain a complete, current inventory of their AI systems. Gartner's research points to why that gap is opening fast — the average Fortune 500 company is on pace to run more than 150,000 AI agents by 2028, task-specific agents are set to appear in 40% of enterprise applications by the end of 2026 (up from under 5% in 2025), and only 13% of organizations believe their governance can keep up.

## Where's the construction version of this problem?

It's already live. Procore's Agent Builder came out of open beta preview at Groundbreak 2025 as a no-code tool: any project team member can build a custom AI agent, or start from a pre-built Starter Agent, without writing anything. Two of the flagship Starter Agents are an RFI Creation Agent, which drafts RFI content and searches project documents for answers, and a Daily Log Agent, which automates jobsite reporting. Autodesk and Trimble are shipping their own AI layers on the same timeline, each with its own agents pulling from project, cost, and schedule data.

None of that runs through Dataiku, Bedrock, or any platform its new product currently watches. That's the honest limit here — a GC can't buy Dataiku's tool and point it at Procore today. But the underlying pattern is the same one Dataiku is selling a fix for: agents get built project by project, PM by PM, with real access to RFI history, daily logs, and — on some builds — labor and cost data, and no one above the individual project owns a list of what exists.

| | Enterprise AI sprawl (Dataiku's target) | Construction's version, today |
|---|---|---|
| Who can create an agent | Any team with platform access | Any PM or coordinator with Procore's Agent Builder |
| Central inventory | Rare — under 1 in 5 have one | Effectively none |
| Data at risk | Customer records, production systems | RFI/submittal history, daily logs, on some builds payroll or cost data |
| Governance today | Emerging vendor tools like this one | None built for construction platforms yet |

## What should a GC or sub do this week?

Skip waiting for a construction-specific version of Dataiku's product and build the manual equivalent: a single list, owned by ops or IT, of every AI agent running across the company's software — what platform it's on, who built it, what project or financial data it can read, and whether it only produces a draft or is allowed to submit, send, or execute on its own. An RFI Creation Agent that only drafts is a productivity tool. One that's been toggled to auto-submit can commit the company to a position in a dispute without a person reading it first, and on a certified-payroll job, a Daily Log Agent that's been given labor data is touching information with real compliance exposure if it's mishandled. The distinction between "drafts" and "acts" is exactly the axis Dataiku's risk tiering is built on — a construction firm doesn't need to buy the software to start asking the same question about its own agents.
